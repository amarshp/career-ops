# Application Constraints

Hard rules enforced on every application cycle. Check ALL before applying to any role.

---

## 1. Job Posting Age - 30 Days Max

Skip any job posted more than 30 days ago.

- Today is dynamically determined each session (check memory or date)
- Cutoff = today minus 30 days
- Always verify posting date on the INDIVIDUAL job page, not the search result snippet
- When no date is visible on the job page, look for "Posted X days ago" text
- If date cannot be confirmed, skip the job

## 2. Role Relevance - Must Match Experience

Only apply to roles that genuinely match Amarsh's background as a Senior AI Engineer.

Amarsh's core experience:
- Agentic AI systems (LangGraph, Claude, MCP, tool orchestration)
- Production GenAI / LLM applications (RAG, LangChain, prompt engineering, evaluation)
- Applied ML (segmentation, computer vision, OOD detection, uplift modeling)
- MLOps / LLMOps (CI/CD, model deployment, observability)
- Enterprise AI / DevOps automation
- Data pipelines and feature engineering

REJECT outright if the role is primarily:
- Deep model compression research (QAT/PTQ quantization, knowledge distillation, pruning as the core skill)
- 3D art, animation, game design
- Pure data science with no engineering component
- Hardware/chip design
- Network/telecom engineering
- Finance quant / algo trading
- Pure project management with no technical AI content
- Pure software engineering with no AI/ML component
- PhD-only research positions with publications required

ACCEPT if the role title is in or adjacent to:
- Senior AI Engineer / AI Engineer
- Machine Learning Engineer / Senior ML Engineer
- Applied AI Engineer
- Agentic AI / Autonomous Systems Engineer
- Generative AI Engineer / GenAI Engineer
- LLM Engineer
- AI Platform Engineer / LLMOps Engineer
- MLOps Engineer / AI Infrastructure Engineer
- Data Scientist (applied, not pure stats)
- AI Solutions Architect / Forward Deployed AI Engineer
- AI Consultant / Senior AI Consultant (technical)
- Computer Vision Engineer (only if Amarsh has stated relevant CV experience)
- NLP Engineer
- Senior Software Engineer - AI/ML focus

When unsure, apply the smell test: "Would a recruiter reading Amarsh's resume call him back for this?" If no, skip.

## 3. Location - Gulf Countries Only

Only apply to jobs in:
- United Arab Emirates (Dubai, Abu Dhabi, Sharjah, Ajman, UAE Remote)
- Saudi Arabia (Riyadh, Jeddah, Dammam, KSA Remote)
- Qatar (Doha, QA Remote)
- Kuwait
- Bahrain
- Oman (Muscat)

Skip jobs in:
- India, Pakistan, UK, Europe, US, or any non-Gulf country
- Unless explicitly marked "Remote - open to Gulf candidates" or similar

## 4. Excluded Companies

- Space42: reserved for Pranav Balaji referral. Do NOT apply through the portal. Skip all Space42 listings.

## 5. Skip LinkedIn

LinkedIn application automation is not possible. Do NOT attempt to apply via LinkedIn. If the only application path is LinkedIn Easy Apply, mark as Manual and move on.

## 6. Minimum Compensation

Target: AED 30,000/month (or equivalent).

- Skip roles that explicitly state a salary below AED 30K/month
- If salary is not stated, proceed (do not assume it's too low)
- For USD-denominated roles: AED 30K/month = approx USD 98K/year = approx USD 8,200/month

## 7. No Em-Dashes or Double-Dashes in Output

Never use em-dash (--) or double-dash in any text output, TSV entries, cover letters, or form answers. Use a period, comma, or semicolon instead.

## 8. No Fabrication of Experience

When filling application forms, only state experience Amarsh actually has. Do not invent:
- Publications or conference papers
- Specific quantization/compression ratios
- Projects that do not exist in his profile

If a form requires experience Amarsh does not have (e.g., PhD + publications in model compression), skip the role rather than fabricating answers.

## Quick Decision Checklist (run before every application)

- [ ] Posted within last 30 days?
- [ ] Role relevant to Senior AI Engineer experience?
- [ ] Located in Gulf country?
- [ ] Not Space42?
- [ ] Application path is not LinkedIn-only?
- [ ] Salary (if stated) meets AED 30K+ threshold?
- [ ] No fabricated experience required?

All YES = proceed. Any NO = skip.
