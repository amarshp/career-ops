# Resume Norms: Singapore
Last updated: 2026-05-29
Source: MOM EP requirements, MyCareersFuture conventions, SGP tech recruiter feedback

## Mandatory inclusions

- **Nationality**: Include. Singapore's EP eligibility assessment depends partly on nationality. Indian nationals are in the Fair Consideration Framework (FCF) but this is not a blocker for senior tech roles — state it clearly.
- **EP sponsorship requirement**: Must appear in summary or a dedicated line. Exact phrasing:
  > "Require Employment Pass (EP) sponsorship."
  Do NOT say "visa required" (too vague) or "need work authorization" (US framing). Singapore-specific phrasing is "Employment Pass."
- **Current location + relocation intent**: "Bengaluru, India — open to relocation to Singapore."
- **LinkedIn URL**: Critical. SGP tech recruiters validate LinkedIn first.
- **GitHub URL**: Important for technical roles at startups and regional tech companies (Grab, Sea, Carousell).

## Prohibited / omit

- **Photo**: Not required. Some traditional SGP employers (banking, finance) historically requested it, but modern tech hiring does not. Default: omit.
- **NRIC / FIN number**: Never include. Only required post-offer.
- **Religion / ethnicity**: Never include.
- **Salary expectation**: Do not include on resume.

## Length

- **Strictly 1–2 pages**. Singapore recruiters are known to discard resumes beyond 2 pages.
- For Amarsh's profile (6+ years): **2 pages maximum, aim for tight 2**.
- Every bullet must earn its place — SGP recruiters read fast and want quantified impact.

## Photo

- **Default: omit.** Modern SGP tech companies use ATS (Greenhouse, Lever, Workday) which ignore photos.
- Exception: if a SGP recruiter emails directly and their template clearly includes a photo slot, you may add one.

## Work authorization statement

Add as the final sentence of Professional Summary:

> "Require Singapore Employment Pass (EP) sponsorship to work in Singapore."

Or in the header contact line:

> Location: Bengaluru, India → Targeting Singapore | Require EP Sponsorship

## Format

- **Paper**: A4
- **Sections**: same Western order — Summary, Experience, Projects, Education, Skills
- Bullet points: tight, quantified, action-verb-first
- **No "References available on request"** — omit entirely

## ATS / portals

- **MyCareersFuture**: Singapore government job portal. Some companies post here. PDF upload + profile form. Locals/PRs prioritised by law (FCF), but EP-eligible foreigners can still apply.
- **LinkedIn**: SGP companies use LinkedIn heavily. Profile must be consistent with resume.
- **Greenhouse / Lever / Ashby**: Used by Grab, Sea Group, Shopee, Stripe SG, ByteDance SG, Google SG. Standard PDF apply.
- **Workday**: DBS, OCBC, Visa SG use Workday. Copy-paste into form fields AND upload PDF.

## Summary framing

Lead with production systems + quantified impact, close with EP sponsorship:

```
Senior AI Engineer with 6+ years delivering production agentic systems and enterprise GenAI platforms.
At OpenText: built AI Cockpit (multi-agent planning automation, 10x faster project delivery) and a
LangGraph self-healing CI/CD migration agent (12x acceleration, adopted by 10+ teams). Specialised in
RAG, multi-agent orchestration, LLMOps, and MCP tooling. Open to Singapore roles in agentic AI engineering;
require Employment Pass (EP) sponsorship.
```

Key SGP market phrases to inject where authentic:
- Quantified metrics are more valued here than anywhere — lead every bullet with a number
- "FinTech", "GovTech", "super-app", "regional scale" resonate for SGP employers
- "production ML systems" and "platform engineering" signal SGP tech maturity expectations

## Red flags to avoid

- Do NOT submit a 3-page resume — SGP recruiters will not read past page 2
- Do NOT omit EP sponsorship requirement — it creates friction later in the process
- Do NOT use US Letter format
- Do NOT use vague location ("Asia") — be specific: "Bengaluru → Singapore"
- Do NOT list every technology you've ever touched in Skills — SGP recruiters value depth over breadth signal; keep Skills to verified proficiencies
