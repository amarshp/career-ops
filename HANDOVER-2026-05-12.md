## CAPTCHA Findings

- **Cloudflare Turnstile** cannot be solved in a headless Playwright browser. The widget renders in a cross-origin iframe that blocks programmatic interaction. Even clicking the checkbox coordinates does nothing.
- **hCaptcha** requires visual image selection, impossible in headless mode.
- **Recommendation for Codex:** Do NOT attempt CAPTCHA solving. These 3 applications require the user to open the URLs in their own browser. A headed Playwright script (`apply-captcha.mjs`) was created but the user needs to run it from their terminal with `! node apply-captcha.mjs`.
